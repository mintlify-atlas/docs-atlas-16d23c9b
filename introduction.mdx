OpenSC is a set of open source libraries and utilities for working with cryptographic smart cards and security tokens. It provides a unified PKCS#11 interface, PKCS#15 data structure support, and a Windows MiniDriver — enabling applications to use smart card keys and certificates for authentication, signing, and encryption across Linux, macOS, and Windows.

## What OpenSC provides

OpenSC delivers three main integration points for smart card functionality:

<CardGroup cols={3}>
  <Card title="PKCS#11 Module" icon="shield-halved" href="/concepts/pkcs11">
    A standard PKCS#11 shared library loadable by browsers, SSH, and any PKCS#11-aware application
  </Card>
  <Card title="PKCS#15 Support" icon="id-card" href="/concepts/pkcs15">
    Read and write standardized PKCS#15 data structures for keys, certificates, and PINs on smart cards
  </Card>
  <Card title="Windows MiniDriver" icon="microchip" href="/concepts/architecture">
    Native Windows Smart Card MiniDriver for seamless integration with Windows logon and CNG
  </Card>
</CardGroup>

## Supported cards

OpenSC supports more than 40 smart card types and national eID cards, including PIV, OpenPGP, CAC, GIDS, SmartCard-HSM, and national eID cards from Estonia, Germany, Belgium, Portugal, and more.

## Get started

<Steps>
  <Step title="Install OpenSC">
    Download the installer for your platform from [GitHub Releases](https://github.com/OpenSC/OpenSC/releases/latest) or use your system's package manager.
  </Step>
  <Step title="Connect your smart card">
    Insert your smart card into a PC/SC-compatible reader. Run `opensc-tool --list-readers` to confirm the reader is detected.
  </Step>
  <Step title="List card contents">
    Run `pkcs15-tool --list-certificates` to see certificates stored on your card, or `pkcs11-tool --list-objects` via the PKCS#11 module.
  </Step>
  <Step title="Use with your application">
    Configure your browser, SSH client, or application to use the OpenSC PKCS#11 module for authentication and signing.
  </Step>
</Steps>
